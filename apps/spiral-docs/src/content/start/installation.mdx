# 安装

## 环境要求

- Node.js 20+
- pnpm 9+

## 在 monorepo 中使用

Spiral 2 当前以 workspace 包形式发布：

```bash
pnpm add @aviala-design/spiral @aviala-design/tokens @aviala-design/icons
```

## 引入样式

在应用入口引入 Spiral 样式与 ALD 主题：

```tsx
import "@aviala-design/spiral/styles.css";
import "@aviala-design/tokens/ald-theme.css";
import "@aviala-design/tokens/input-effects.css";
import "@aviala-design/tokens/basic-input-effects.css";
import "@aviala-design/tokens/button-effects.css";
```

按需引入其他组件的效果样式（如 `popover-effects.css`、`cascader-effects.css` 等）。

## 挂载 ThemeProvider

```tsx
import { ThemeProvider, Button } from "@aviala-design/spiral";

export function App() {
  return (
    <ThemeProvider defaultMode="light" defaultPresetId="ald">
      <Button mode="primary">开始使用</Button>
    </ThemeProvider>
  );
}
```

## 本地开发

在 Spiral2 仓库中：

```bash
pnpm install
pnpm sync:ald
pnpm --filter @aviala-design/tokens build
pnpm --filter @spiral/spiral-docs dev
```

文档站默认运行在 `http://localhost:5175/docs/spiral/`。
