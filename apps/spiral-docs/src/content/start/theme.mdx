# 主题

Spiral 2 通过 `ThemeProvider` 与 `@aviala-design/tokens` 主题引擎管理亮色/暗色模式、品牌主色与 **base-numbers 密度**。

## ThemeProvider

```tsx
import { ThemeProvider } from "@aviala-design/spiral";

<ThemeProvider
  defaultMode="light"
  defaultPresetId="ald"
  defaultDensity="default"
>
  {children}
</ThemeProvider>
```

## 密度：Default 与 Mobile Friendly

ALD `base-numbers` 提供两套尺寸令牌：

| 令牌示例 | Default | Mobile Friendly |
| --- | --- | --- |
| `--size-regular` | 14px | 18px |
| `--line-height-regular` | 18px | 24px |

切换方式：

```tsx
import { useTheme } from "@aviala-design/spiral";

function DensitySwitch() {
  const { density, setDensity } = useTheme();
  return (
    <button type="button" onClick={() => setDensity("mobile-friendly")}>
      当前：{density}
    </button>
  );
}
```

或在 CSS 中，Mobile Friendly 规则挂载于 `[data-density="mobile-friendly"]`。

## 预设与主色

`useTheme()` 还提供 `setMode`、`setPrimaryColor`、`applyPreset` 等 API，偏好会写入 `localStorage`（键名默认 `aviala-theme`）。

使用文档顶栏的 **浅色/深色** 与 **Default / Mobile Friendly** 按钮即可实时预览组件在不同主题下的表现。
