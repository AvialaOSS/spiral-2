# Spiral 2 介绍

Spiral 2 是 Aviala Design 的 React 组件库，基于 Radix UI、Tailwind CSS v4 与 ALD 设计令牌构建，与 Figma 组件规范保持对齐。

## 特性

- **设计令牌驱动**：主题、密度（Default / Mobile Friendly）与 ALD 同步
- **可访问性**：基于 Radix 原语，支持键盘与屏幕阅读器
- **组合式 API**：Select、Cascader、ColorPicker 等复杂组件采用可组合结构
- **TypeScript 优先**：完整的类型导出与 Props 文档

## 适用场景

- 内部产品界面开发
- 需要与 Aviala Design 设计稿一致的体验产研项目
- 需要主题切换与品牌色扩展的设计系统落地
